## Backend Project Structure

The backend FastAPI project will be created in a new directory at:

```
Week_6/backend/
```

This will follow the structure outlined in `Repository_structure.md`:

```
backend/
  app/
    api/
    core/
    crud/
    db/
    models/
    schemas/
  Dockerfile
```

All backend source code, migrations, and configuration will reside here.
